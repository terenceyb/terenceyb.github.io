1. 认识存知

存知是一款人脉管理工作台，帮你回答三个问题：

  • 今天该联系谁？ —— 工作台的「走动提醒」会根据你为每个人设定的联系频率，提示哪些关系正在冷却。
  • 上次聊了什么？ —— 每个人脉都有互动时间线，记录备注、见面、通话、礼物往来。
  • 我的数据是不是我的？ —— 所有数据存在你设备本地；你可以把它打包成一个 .czdb 数据包文件，放在任何地方，用存知打开、编辑、带走。

存知不做销售漏斗，也不追求「录入多少人」。它关心的是：你有没有把该维持的关系维持住。

2. 第一次打开：三种开始方式

打开存知后，你会看到三个选项：

方式 适合谁 会发生什么
从零开始 想建立自己体系的人 空工作区：0 人、0 标签、0 群组、0 待办。只有 14 个默认字段和 3 个系统视图。标签和群组完全由你自己建
先看看示例 想先体验功能的人 加载一份示例人脉、示例标签与群组，随便点、随便改。顶部有「清空示例数据，从零开始」按钮
打开数据包 已有 .czdb 文件的人 选择文件后，所有人脉、字段、标签群组、待办、纪念日、附件、设置一并还原

> 小提示：从零开始模式下，第一次进人脉页会看到空态引导「可先建一个群组（如：同事、客户）来分类」，点一下就能建。

3. 工作台：每天从这里开始

工作台是你每天打开存知的第一屏。

3.1 本周概览

顶部一行统计：人脉总数、本周已联系人数、本周待办完成率、最近备份时间。手机上是一行可左右滑动的胶囊，电脑上是完整概览条。

3.2 走动提醒

这是存知的核心。它会告诉你：谁该联系了。

  • 每个人脉可以设置联系频率：每周 / 每两周 / 每月 / 每季度 / 每半年 / 每年 / 自定义天数。
  • 逾期越久，排得越靠前。每条提醒显示：头像、姓名、上次互动时间、逾期天数、上次聊到的摘要。
  • 点击提醒的姓名、头像或空白处 → 直接进入该人脉详情页。
  • 点 「已联系」 → 计时器重置，这条提醒消失，不会进入详情。
  • 点 「稍后」 → 可选 1 天 / 3 天 / 1 周后再提醒。
  • 如果你连续两次忽略同一个人的提醒，第三次它的排序会自动降低，避免反复打扰。这个机制可以在「设置 → 提醒策略」里关掉。

> 来自智能视图的提醒会标注来源，比如「来自：待补电话的客户」，让你知道它为什么出现。

3.3 待办事项

待办是和人脉关联的，不是通用待办。

  • 分「今天 / 本周 / 逾期」三段折叠展示。
  • 可以从人脉详情页直接为 TA 创建待办（比如「下周约咖啡」），创建后自动回到工作台。
  • 完成待办时，如果关联了人脉，可以选择「同时记为一次互动」，参与走动提醒的冷却计算。
  • 新建待办时，「关联人脉」是一个可搜索的选择器：输入姓名、公司、标签，甚至拼音首字母（比如 zs 命中「张三」），回车选中。也可以不关联任何人，作为全局待办。

3.4 纪念日提醒

支持生日、入职纪念日、合作周年、自定义纪念日。

  • 展示未来 7 天内的纪念日，当天到期会高亮。
  • 快捷动作：复制祝福文案、记录备注。
  • 在「年龄与生日」字段填了生日的人脉，可以一键创建生日纪念日。

3.5 速记

记忆往往产生在你离开应用之后，所以速记的入口必须够低。

  • 手机：工作台底部悬浮「速记」按钮，点开是全屏编辑页。
  • 电脑：任意页面按 ⌘/Ctrl + Shift + N，弹出居中速记框，写完不打断你手头的事。

速记可以：

  • 输入内容后，系统会建议关联对象（姓名模糊匹配 + 最近查看的人脉），你确认后写入 TA 的时间线。
  • 选择事件类型：普通备注 / 电话沟通 / 见面 / 微信沟通 / 邮件 / 礼物。
  • 选「礼物」后，会多出「礼物内容」（必填）、「价值」（可选，单位元）、「我送出 / 我收到」三个字段。提交后时间线显示为「送出礼物：茶叶礼盒（¥300）」。
  • 一次关联多人。

> 速记输入框打开后光标会自动落在输入框里，连续打字不会被打断。按 Esc 关闭。

4. 人脉：名片卡、详情页与关系网

4.1 名片卡

每张名片卡参考 Apple Wallet 的凭证风格。正面只放 6 项信息，一眼能看完：

头像 · 姓名 · 公司/单位 · 群组 · 标签（最多 3 个） · 脱敏电话
  • 电话脱敏显示138****1234），点一下直接拨号。
  • 点卡片右上角翻转图标，可以看背面：地址、生日、婚姻状况、爱好、城市、关联人、引荐人等补充信息，最多 8 项。
  • 长按卡片（电脑端右键或 hover）出现快捷菜单：拨打电话、复制电话、编辑、设置提醒、删除。

4.2 详情页

详情页从上到下分四块：

① 基础信息：头像、姓名、公司、群组、标签、电话、邮箱、地址等。

② 自定义字段：你在字段管理里启用的自定义字段都会出现在这里。空值默认不显示（设置里可以改成「显示空字段」）。

③ 互动时间线：倒序展示备注、完成的待办、已联系记录、纪念日、礼物往来、字段变更。每条带时间戳和类型图标，可以按类型过滤。

④ 关系备忘：自由文本区，写不适合结构化的信息（比如「介绍人是李总，偏好喝茶，避免周五下午联系」）。备忘内容参与全局搜索。

关于点击字段编辑：

  • 点击字段的标签或值 → 进入编辑。
  • 电话、邮箱、地址、链接这类字段，右侧有操作按钮（电话、短信、复制、打开链接）。点按钮只执行按钮动作，不会进入编辑。
  • 进入编辑后，操作按钮暂时隐藏，换成「保存 / 取消」，避免误触。

记录一次联系：

详情页右上角有一个「记录互动」图标（对话气泡+加号），不是对号。点它不会直接记一条「已联系」，而是：

  1. 光标自动落到互动时间线的输入区；
  2. 默认通道为「微信」，可切换成电话、见面、邮件等；
  3. 你写下内容后按回车提交，时间线出现这条记录；
  4. 如果你只想标记「联系过了」不写内容，输入区右侧有「仅标记已联系」文字按钮。

4.3 关系网

关系网在人脉页的视图切换里，分三个子模式：

子模式 回答的问题
全览 我的网络长什么样？谁和谁有关联？
引荐树 我的人脉主要是谁带来的？
两人之间 这两个人认识吗？我们共同认识谁？

全览模式：

  • 默认只显示「我」和第一圈层的人脉节点，节点之间没有连线，避免一上来就是一张密网。
  • 节点按群组着色；90 天内互动过的不透明，超过 90 天的半透明，一眼看出哪些关系在冷却。
  • 点击某个节点，才显示它和其他可见节点之间的关联线，旁边浮出轻量预览卡（头像、姓名、群组、上次互动时间、查看详情 / 记录互动）。
  • 同一时刻只高亮一个节点。
  • 关系网是只读的：不能拖拽节点、不能画线、不能删线。所有关系修改都回到人脉详情页改「关联人」或「引荐人」字段。

引荐树：以「我」为根，按引荐人字段展开。桌面是横向树状图，手机是分组列表。引荐人为空的人归入「直接认识」。

两人之间：选「从」和「到」两个人，系统算最短关联路径（最多 4 跳）。没路径时显示「暂无已知关联」，并列出共同群组、共同标签作为弱关联参考。桌面端有路径图，手机端给文字结论 + 共同认识的人列表。

5. 我的名片：让网络中心有名字

存知不需要账号，但「我」在关系网里需要一个可识别的身份。

  • 入口：工作台左上角头像，或设置 → 我的信息。
  • 可以设置：头像、昵称（必填，默认「我」）、一句话介绍（最多 40 字）、电话、邮箱、地址、公司/单位、城市。
  • 它会出现在：工作台左上角、关系网中心节点、导出名片册的封面、分享出去的名片。

重要边界：我的名片只描述「我」，不会出现在人脉列表里，不计入人脉总数，搜索昵称也搜不到它，不能作为关联人或引荐人的引用对象。

第一次打开关系网时，如果你的昵称还是默认的「我」，会弹一个轻提示「给网络中心的自己起个名字吧」，可以跳过。

6. 搜索、筛选与智能视图

6.1 搜索

  • 手机：人脉页顶部搜索栏，点击后从顶部下拉出搜索面板。结果少时面板自动收缩，不会留一大片空白；没结果时只显示一行「没有找到相关联系人」。软键盘弹起时面板贴齐键盘上沿。
  • 电脑：任意页面按 ⌘/Ctrl + K 唤起搜索，不离开当前页↑/↓ 切换结果Enter 打开Esc 关闭。

搜索覆盖：姓名（支持汉字、全拼、拼音首字母，比如「张伟」可以用 zhangwei 或 zw 搜到）、电话（忽略空格横线）、邮箱、地址、公司、城市、群组、标签、备注、多行文本、互动记录、单选多选选项、数字、日期、链接文字与网址、条码值、附件文件名。

结果按联系人聚合，命中字段高亮。空输入时显示「最近查看」和「最近添加」。搜索历史保留最近 10 条。

6.2 筛选

  • 手机：底部抽屉，条件以胶囊堆叠，实时预览结果数量。
  • 电脑：筛选栏常驻列表区顶部，条件行内编辑，条件之间可切「且 / 或」。

可筛：群组、标签（包含任一 / 包含全部）、某字段有值 / 为空、字段值（按类型给对应操作符）、互动活跃度、生日月份、引荐关系、锁定字段组合（比如「电话为空 且 引荐人非空」）。

6.3 智能视图

把一组筛选条件存下来，命名为一个视图，比如「本月要联系的客户」「由王总引荐且未记录电话的人」。

  • 手机：筛选抽屉顶部有一排视图胶囊条，横向可滑。点一下就应用该视图的筛选，当前视图高亮并显示命中人数。关闭抽屉后，人脉列表顶部显示当前视图名称胶囊，点它可以重新打开。
  • 电脑：左侧栏有智能视图列表，点击即切换。
  • 内置三个系统视图（不可删）：「全部人脉」「最近添加」「待补全信息」（字段完整度低于 60%）。

条件组（进阶用法）：

如果你需要「不同人群不同条件」，可以点筛选区底部的「添加条件组」。默认新建视图就是一个平铺的条件列表，只做简单筛选的人永远不会看到「条件组」这个概念。

加了条件组之后，规则会变成嵌套结构，比如：


匹配以下任一条件组：
├─ [组 1] 同时满足：群组=客户、标签含「重点」、超过 14 天无互动
├─ [组 2] 同时满足：群组=投资人、超过 30 天无互动
└─ [组 3] 同时满足：生日在 7 天内、电话不为空
  • 每组独立选「且 / 或」，最多 3 层嵌套，单个视图最多 20 个条件。
  • 编辑时右侧常驻命中漏斗：每层条件筛完剩多少人一目了然，规则写空了能立刻看出是哪一层筛没的。
  • 手机上规则树只读，可以整体启停、删顶层条件；嵌套编辑在电脑上做。

把视图用于走动提醒：

在智能视图详情里打开「用于走动提醒」，并设置该视图内人脉的统一联系频率（比如 14 天）。

  • 优先级：个人级频率 > 视图级频率 > 全局默认频率。你手动给某人设过频率的，不会被视图覆盖。
  • 多个视图重叠时，取最短频率（更勤的提醒优先），管理页会提示重叠人数。

7. 数据包：把数据握在自己手里

7.1 两种存储方式

方式 数据在哪 适合谁
仅本地 浏览器 IndexedDB 首次使用、轻度使用。靠导出 JSON / CSV 备份
数据包 一个 .czdb 文件 + IndexedDB 工作副本 长期使用、多设备迁移、想让数据「看得见摸得着」

数据包本质是一个 UTF-8 的 JSON 文本文件，用任何文本编辑器都能打开检查。你的数据对你完全可见。

7.2 加载与实时保存（电脑 Chrome / Edge）

  1. 设置 → 数据包管理 → 打开数据包，选择 .czdb 文件。
  2. 应用校验文件、必要时迁移格式，然后进入正常工作状态。
  3. 顶部或侧栏显示：文件名、最后保存时间、保存状态（已保存 / 保存中 / 有未保存更改 / 保存失败）。

之后你的任何修改都会自动写回这个文件：

  • 停止操作 2 秒后触发保存；编辑密集时每 30 秒强制保存一次。
  • 无变更时每 5 分钟检查一次文件有没有被外部改动。
  • 写入时显示「保存中」，此时关闭页面会被拦截。
  • 保存失败（权限撤销、磁盘满、文件被占用）会弹红色横幅，提供「重试 / 另存为 / 查看详情」，未保存内容暂存应急区，下次打开可恢复。

页面刷新后需要重新确认文件权限，会有一个不打断的提示条「点击重新授权以继续自动保存」。

7.3 在 Safari、Firefox、手机上

这些环境不能常开文件实时回写，所以：

  • 打开数据包：读完就载入工作副本，原文件不被持有。
  • 修改数据：正常存本地，状态栏显示「本次会话未关联文件」。
  • 想存回文件：点「导出覆盖」，生成同名文件手动替换原文件。
  • 有未导出变更时离开页面，会提示「有 N 项更改尚未写回数据包」。

所以手机端的定位是：数据包的查看器和速记器。需要长期维护数据包时，把 .czdb 放到同步盘或隔空投送到电脑上编辑。

7.4 冲突处理

如果文件被其他程序或其他设备（通过同步盘）改过，存知下次保存前会发现，弹出冲突对话框：

  • 重新加载：放弃本地未保存变更，载入文件最新内容。
  • 覆盖保存：以本地版本覆盖文件。
  • 另存为：把本地版本存成新文件，两份都保留。

对话框会显示双方最后修改时间和修订号。存知永远不会静默覆盖。

同一浏览器多个标签页打开同一数据包时，后打开的标签页进入只读模式并提示已占用。

7.5 备份与加密

  • 每次成功载入数据包，如果距上次备份超过 24 小时，自动在 IndexedDB 生成快照（最多 5 份，滚动淘汰）。
  • 设置 → 数据包管理里有「数据包快照」列表，可查看时间、大小、人脉数量，一键恢复。
  • 电脑端可以设置「每次保存前在同目录生成 .bak 副本」（需要额外授权目录权限）。
  • 数据包可以加口令加密（AES-GCM），载入时要求输入口令，口令不存设备。加密后文件无法被文本编辑器直接查看，默认关闭。

8. 导入与导出

8.1 导入

支持 CSV、vCard（.vcf）、存知 JSON 快照.czdb 数据包。

三步向导：

  1. 上传与预览：CSV 需含表头；vCard 直接解析。展示前 20 行预览。超过 5000 条会提示分批。电脑端可以直接把文件拖进窗口。
  2. 字段映射：系统自动匹配列名phone / 电话 / Tel → 电话）。每个源字段选一个目标字段，或「创建为新自定义字段」，或「忽略」。多值字段（多个 TEL）可选「合并为一个字段（分号分隔）」或「仅保留第一个值」，预览即时反映。电脑端支持拖拽映射并保存模板复用。
  3. 冲突处理：按「姓名 + 电话」检测重复，策略选跳过 / 覆盖 / 作为新记录导入。执行后显示成功、跳过、失败条数，失败记录可下载错误报告 CSV。

单次上限 2000 条，文件 ≤10MB。vCard 照片当前版本不导入，结果里会注明。

合并导入 .czdb 或 JSON 时，按人脉 ID + 更新时间做记录级合并，冲突项列出字段级差异，你逐条或批量选保留哪一侧。永不静默覆盖。

8.2 导出

格式 用来做什么 包含什么
.czdb 完整数据包、多端迁移 全部数据，含字段定义、附件、设置
CSV 通用备份、迁移到表格或其他 CRM 所有内置 + 自定义字段，一行一人脉
vCard 导入手机通讯录或其他联系人应用 姓名、电话、邮箱、公司、职务、地址、备注，照片内嵌
JSON 完整快照、自托管迁移 字段定义 + 人脉 + 分组标签 + 待办 + 纪念日 + 时间线

CSV 多值标签用分号分隔，日期 ISO 8601。文件名格式 存知_导出_YYYYMMDD_HHmm.csv。导出都在你设备本地生成，不经过服务器。

电脑端还支持：

  • 用 File System Access API 固定导出位置并记住，之后一键覆盖写入，方便配合同步盘定期备份。
  • 只导出表格里选中的那几个人脉。
  • 导出名片册 PDF（每页 6 张卡片，首页是我的名片封面），适合线下活动前打印。

9. 设置详解

9.1 移动端的设置页

手机上点「设置」，看到的是一个纵向列表：我的信息、字段管理、数据包管理、导入导出、提醒策略、智能视图管理、数据健康、字段变更审计、隐私与安全。点任意一项进入子页面，左上角返回。

电脑端设置页是左侧二级导航 + 右侧内容区。侧栏一级只有「工作台 / 人脉 / 设置」三项，没有单独的「字段管理」入口——字段管理在设置里面。

9.2 字段管理

  • 内置 14 个默认字段，其中姓名、电话、互动记录、引荐人是锁定字段：不能删、不能改类型、不能改 key、不能改必填状态，但可以改显示名（比如把「姓名」改成「称呼」），也可以拖拽调顺序。
  • 其他字段可以新增、编辑、删除、禁用。
  • 删除字段：二次确认，会列出受影响人脉数量，删除前自动生成保留 7 天的本地快照。
  • 禁用字段：数据保留，详情页和名片卡不再展示，随时可重新启用。删除确认弹窗里会把「禁用」作为推荐操作提示。
  • 字段列表里「必填」「可见」两列严格上下对齐。锁定字段的删除和禁用按钮也会显示，但呈浅灰不可点击态，鼠标悬停有说明——保证每一行的按钮位置一致，视线扫过去不断档。
  • 「禁用字段」按钮用的是「禁止」图标（斜杠圆），不是对号，不会让人误以为是确认。

14 种字段类型：

  • 常规：单行文本、多行文本（支持表情和换行）、单选、多选、日期（日期或日期+时间，多种格式）、附件（文件/图片）、数字（可设小数、百分比）、复选框、链接（网页卡片形式显示）
  • 业务：电话号码（一键拨号）、邮箱（格式校验）、地址、条码（扫码识别二维码/条形码）
  • 引用：人脉引用（关联人、引荐人等）

9.3 提醒策略

  • 走动提醒的默认联系频率（新人脉的初始值）。
  • 每日提醒推送时间（默认 09:00）。
  • 纪念日提前提醒天数（默认 3 天）。
  • 是否启用「连续忽略降低权重」（默认开启）。

电脑端用应用内角标和顶部通知条提醒；浏览器系统通知需要你授权，没授权就降级为应用内提示，不反复弹窗。

9.4 智能视图管理

列出所有视图（含系统和自定义），显示名称、图标、命中人数、是否用于走动提醒、重叠提示。可重命名、改图标颜色、删除（系统视图不可删）、整体启停。规则结构只读展示，编辑回到筛选抽屉/筛选栏。

9.5 数据健康

扫描并列出：

  • 缺少电话或邮箱的人脉
  • 缺少头像的人脉
  • 疑似重复的人脉
  • 超过 90 天无互动的人脉
  • 生日在 30 天内但没设纪念日提醒的人脉
  • 引用了已删除联系人的字段

每一项可以点击跳到对应筛选视图，一键处理。

9.6 字段变更审计

删除或禁用自定义字段、锁定字段改名等关键操作，会记录在数据包的审计日志里（最近 200 条）。误操作时可以据此判断恢复范围。

9.7 隐私与安全

  • 所有结构化数据默认存本地或你持有的数据包，不上传服务器，无需账号。
  • 可选加密备份。
  • 「一键清除所有数据」需要输入确认短语，清除 IndexedDB、Cache Storage、localStorage 里的全部存知数据。
  • 电脑端可以设 4 位 PIN「锁定应用」，离开工位一键锁定，解锁前不渲染任何人脉数据（防肩窥，不是安全边界）。

9.8 关于备份提醒

存知不会在所有页面顶部常驻「IndexedDB 可能被清理」的横幅。只在你本次会话第一次进入、且距上次备份超过 30 天时，右下角弹一次 Toast：「数据存在浏览器里，建议导出一次数据包做兜底」，带「去备份」按钮，6 秒后自动消失，本次会话不再出现。

数据包模式、只读模式、写盘失败等真正代表异常的状态提示会保留，因为那是需要你处理的问题。

11. 常见问题

Q：我需要注册账号吗？

不需要。存知没有账号体系，数据在你自己设备上。

Q：换手机/换电脑怎么办？

导出 .czdb 数据包，在新设备上打开它。字段定义、人脉、标签群组、待办、纪念日、附件、设置全部还原。

Q：手机和电脑能自动同步吗？

V1.0 不做实时云同步。有三种方式：① 导出 JSON 在另一台导入；② 用合并导入做记录级对齐；③ 电脑端把 .czdb 放进同步盘目录，由同步盘搬运，存知检测到文件被外部改动会提示你重新加载或覆盖。

Q：浏览器清理数据会丢吗？

有可能（iOS 长期不访问、桌面清除站点数据）。所以要么导出备份，要么使用数据包。这是 Web 应用无法回避的风险，存知能做的就是把备份做得足够容易。

Q：为什么关系网不能画线、不能拖拽节点？

关系网是「关联人」和「引荐人」字段的可视化，不是另一个需要维护的数据结构。你看到的每条线，都能在人脉详情页找到对应字段值。要改关系，去改字段。这样数据只有一个来源，不会出现「图上有线、字段里没有」的矛盾。

Q：我的人脉数据会上传吗？

不会。所有结构化数据默认存本地或你持有的数据包文件，导出也在设备本地生成。

Q：从零开始后为什么没有默认标签和群组？

因为数据是你的。从零开始 = 空库，标签和群组完全由你自己建。想看示例数据，可以在欢迎页选「先看看示例」。

Q：头像上传了为什么不显示？

增补 v1.1 已修复此问题。现在上传成功后 1 秒内，名片卡、详情页、关系网节点、关联人胶囊里的头像都会变成图片，无需刷新页面。如果附件文件缺失，会回退成姓名首字母，并在头像右下角显示一个小感叹号提示。

Q：详情页右上角的对号按钮去哪了？

增补 v1.1 把它换成了「记录互动」图标。点它不会直接记一条「已联系」，而是把光标送到时间线输入区，你写下内容再提交。只标记已联系不写内容，用输入区右侧的「仅标记已联系」文字按钮。

Q：手机上怎么用智能视图？

增补 v1.1 在人脉页筛选抽屉顶部加了视图胶囊条。点胶囊即应用筛选，列表顶部会显示当前视图名称。规则树在手机上只读，嵌套编辑在电脑上做。

12. 实用小技巧

  • 批量整理：电脑端表格视图 Shift 连选⌘/Ctrl 加选，底部浮出操作条，一次给几十个人打标签、改群组、设联系频率。
  • 数据健康是维护入口：每月花 5 分钟看一遍数据健康，补全缺电话的人、处理疑似重复、检查超 90 天没联系的人，比一次性录入几百人有用得多。
  • 用视图代替逐人设频率：给「客户」建一个视图，设 14 天提醒；给「投资人」建一个视图，设 30 天。不用挨个设置，个人手动设过的频率优先。
  • 礼物记录：速记选「礼物」，填内容和价值，选送出/收到。时间线里会显示成「送出礼物：茶叶礼盒（¥300）」，人情往来有据可查。
  • 速记是最高频的入口：手机放悬浮按钮、电脑记快捷键 ⌘/Ctrl + Shift + N。见完人当场记一句，比事后回忆有用。
  • 两人之间：想不起来两个朋友认不认识，用人脉 → 关系网 → 两人之间，选两个人，看有没有路径、共同认识几个人。
  • 配置列：表格视图右上角「配置列」可以勾选显示哪些字段、拖拽列宽。菜单会浮在最上层，靠窗口边缘时自动翻转，不会再被表格遮住。
  • 撤销：电脑端删错东西、改错字段，先试 ⌘/Ctrl + Z。删除自定义字段前系统也会自动留 7 天快照。

> 存知的目标不是让你「管理人脉」，而是让你在恰当的时候想起某个人，并且有东西可聊。如果它做到了这一点，其他功能都是锦上添花。
