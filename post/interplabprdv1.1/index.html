Interplab-口译训练平台 PRD（v1.1）

2026-11-08 · 17 分钟阅读

让口译自学者把每一次练习，都变成可复盘、可对比、可改进的证据。

InterpLab 是一款个人口译自学训练与复盘工具，支持交替传译智能分段训练、带稿与无稿同声传译、影子练习。以双轨波形对齐回放、时间锚点标记和可解释评估线索为核心，让每一次口译练习都留下可定位、可对比、可改进的证据。

1. 产品概述与目标

1.1 背景

口译能力的提升依赖“练习—回听—识别问题—针对性改进”的循环。现有工具大多只解决“播放+录音”的浅层需求：交替传译分段靠手动拖拽，同声传译带稿模式缺乏文本与音频的同步锚定，复盘时源语与译语无法在时间轴上对齐比对。自学者往往在练习结束后陷入“听了，但不知道该改什么”的困境。

本产品定位为面向个人口译学习者的浏览器端自学训练与复盘平台，覆盖交替传译、带稿同声传译、无稿同声传译三种核心训练形态，并以“智能分段—双轨记录—结构化复盘—个人成长追踪”为主轴，补充影子练习、EVS 调节、术语库、训练计划等能力，形成完整的个人训练闭环。

1.2 产品目标

用户目标：让每一次口译练习都能留下可回看、可定位、可对比的证据，使自学者从“凭感觉练”转向“基于证据改”。

产品目标：成为口译自学者高频使用的个人训练工作台，覆盖备考、日常保持、专项突破等自学场景。

1.3 目标用户

用户 描述 核心诉求
口译自学者 口译专业学生、备考 CATTI/NAATI 等考试者、职业译员日常保持训练、口译爱好者 快速开始练习；清晰看到自己的问题；有可追踪的进步记录；无需依赖教师或同学

角色说明：产品仅设“学习者”单一角色。不设教师端、班级、任务布置、批阅、互评等功能。系统运维层面的后台管理不属于面向用户的产品角色，不在本 PRD 范围。

1.4 设计原则

  • 复盘优先于练习：每次训练结束后必须产出可操作的回听与标注界面，而非仅保存录音文件。
  • 分段服务于“句子”，而非“固定秒数”：交传拆分目标是语义完整的意群/句子，时长是约束条件，不是切割依据。
  • 同传交互差异化：带稿同传的文本是导航工具；无稿同传界面应尽量减少认知负荷，两者不共用同一套训练界面。
  • AI 辅助，人来判断：自动评估只给线索和锚点，不给出误导性总分，最终判断权留给学习者自己。
  • 个人数据默认私密：所有素材、录音、复盘记录默认仅本人可见，不设公开素材库与社交化展示。

3. 核心功能详细需求

3.1 个人素材与准备

3.1.1 音频上传与管理

用户可上传训练用源语音频，支持 MP3、WAV、M4A 等常见格式，单文件时长上限建议 60 分钟。上传后系统转码并生成波形预览与基础元信息（时长、采样率）。

编号 功能 说明
A-01 音频上传 拖拽/点选上传，显示上传进度与转码状态
A-02 波形预览与首尾裁剪 可裁剪首尾静音，避免训练时无意义等待
A-03 个人素材库 用户可命名、打标签（主题、难度、口音、语速）、收藏、搜索
A-04 素材难度标注 手动或由系统估算标注语速（WPM）和信息密度等级，供选材参考
A-05 本地素材模式（可选） 支持仅在本地浏览器保存素材索引与录音，不上传云端；适合隐私敏感用户

说明：不设公开素材库、不设他人素材可见性设置。所有素材默认仅当前用户可见。

3.1.2 文本稿件上传与对齐（带稿同传）

用户上传文字稿件，用于带稿同传。理想情况下稿件与音频实现时间对齐，使文本随音频进度逐句/逐词高亮。

对齐方式：

  • 自动对齐（推荐）：若音频经过 ASR，可将 ASR 词级时间戳与上传稿件做文本匹配对齐；措辞差异采用模糊匹配与编辑距离对齐。
  • 手动校准：自动对齐置信度低的句子，用户可在文本视图中点击句子后拖动音频进度条校准；系统记录校准后的时间锚点。

3.1.3 个人术语库与生词本

术语准备是口译训练的前置环节，也是自学中高频出现的痛点。本模块贯穿素材准备、训练和复盘。

编号 功能 说明
T-01 个人术语库 创建多个术语库（按主题/考试/客户），支持手动录入与 Excel/CSV 导入
T-02 从稿件提取术语 上传带稿同传稿件后，系统提取候选术语（名词短语、专有名词、数字表达），用户勾选加入术语库
T-03 训练中术语高亮 带稿同传界面高亮术语库命中的词条；无稿同传复盘时可标注术语使用情况
T-04 记忆卡片复习 基于术语库生成闪卡，支持“已掌握/待复习”标记，形成训练外的轻量复习循环
T-05 生词本 复盘标记为“用词不当/不认识”的词自动进入生词本；也可手动添加

3.2 交替传译训练

3.2.1 智能分段：用户设定时长 + 句子边界浮动

这是产品关键差异化能力。用户输入“期望每段时长”（如 60 秒），系统不在第 60 秒硬切，而是在 60 秒附近的语义边界处断开。

处理流程：

  1. VAD 语音活动检测：识别语音段与静音段，得到候选停顿区间。
  2. ASR 词级时间戳：使用 Whisper 等模型获取词级时间戳；Whisper 原生分段基于时间戳预测而非语法句子边界，需应用层后处理重组。
  3. 句子边界候选生成：综合三类信号打分——标点符号（句号/问号/感叹号权重最高）、停顿长度（超过阈值的长静音）、句法完整性（主谓结构闭合或轻量 NLP 句子切分）。
  4. 浮动约束下的最优化选择：在用户设定时长 ± 浮动范围内选取边界得分最高的位置；若范围内无高置信边界，则向更远边界搜索，并标注“该段为近似切分”。
  5. 输出分段列表：每段包含起止时间、时长、ASR 文本（若有）、边界置信度。

用户可控参数：

参数 说明
期望时长 用户输入目标秒数（如 45s / 60s / 90s）
浮动范围 默认 ±20%，可调 ±10% / ±30%
最小段长 / 最大段长 避免极短或极长段落
切分依据偏好 “优先标点句号” / “优先长停顿” / “平衡”（默认）

分段后编辑：分段结果以列表展示，每段可播放试听、查看 ASR 文本、手动拖拽边界微调、合并相邻段、拆分某段。支持“从第 N 段开始训练”的断点续练。

分段预听与难度预览：正式训练前可快速浏览所有分段波形与时长分布，对过长段落标记“待调整”，开始训练时优先提醒。

3.2.2 逐段训练流程

每个分段遵循“听—记—译—录”循环：

播放控制：

  • 分段播放：当前段从头播放，支持暂停/继续。
  • 重复播放：同一段可重复听，次数不限。
  • 变速播放：0.75× / 1.0× / 1.25× / 1.5×，变速不变调。
  • 源语回放与译语回放分离控制。

录音：

  • 进入“翻译录制”状态自动开始录音，点击“完成本段”停止。
  • 录音前可设置倒计时（如 3 秒）。
  • 录音中显示实时波形与计时器。

数字笔记板（可选增强）：播放源语阶段提供手写/键入关键词的笔记板；复盘时笔记时间轴可与录音回放同步呈现，帮助还原“当时听到了什么、记了什么、译出了什么”。

多轮训练：同一素材支持“回炉”重练，系统保留每一轮录音，便于对比同一段落在不同轮次中的表现变化。

3.2.3 复盘衔接的数据要求

每段训练记录必须包含 segment_index、source_start、source_end、user_audio_start、user_audio_end、attempt_number，以便复盘中精确跳转与对比。

3.3 同声传译训练

3.3.1 带稿同声传译

适用场景：用户拥有讲话稿或字幕文本，一边看稿一边同传输出。文本作用是减轻听辨负担、提供术语与专有名词锚点、帮助预判句法走向。

训练界面布局：

  • 中央主文本区，字号、行距可调。
  • 当前朗读中的句子/短语以高亮底色标识，已读部分淡化，未读部分正常显示。
  • 文本随音频进度滚动，滚动节奏跟随对齐时间戳，而非固定 WPM 匀速滚动。
  • 术语与专有名词（来自个人术语库或系统识别的数字、人名、机构名）以不同颜色/下划线标记。
  • 提供“隐藏文本”开关：训练中可随时切换纯听模式，自我检测是否过度依赖稿件。

丰富功能——文本遮挡训练：可设置“每句末尾几个词遮挡”或“随机遮挡 20% 的短语”，迫使在稿件支撑下仍保持听辨投入，逐步过渡到无稿同传。

丰富功能——段落/发言人分割：若稿件包含多段落或多发言人，训练界面按段落分段，复盘时按段落统计表现。

3.3.2 无稿同声传译

适用场景：仅有音频，模拟真实会议中无稿或无法预知讲稿的同传场景。

训练界面原则：极简、低干扰。无稿同传认知负荷极高，界面不应增加视觉负担。

  • 默认仅显示：播放/暂停、录音状态、计时器、可选 EVS 指示器。
  • EVS 指示器：轻量实现——提供自报告式 EVS 标记，用户可按快捷键标记“跟得太紧/太松”；也可在训练前设定目标 EVS（如滞后源语 2—3 秒），界面以计时器提示当前录音相对播放的粗略时差。EVS 是同传训练核心调控变量，从短到长的滞后控制有助于拓展记忆缓冲能力。
  • 干扰音训练（可选）：可开启低音量背景噪声或竞争语音，模拟同传箱外干扰环境，默认关闭。

语速调节：源语音频支持 0.75×—1.25× 变速播放，帮助从较慢语速逐步适应真实语速。

3.3.3 影子练习与 EVS 专项（同传预备模块）

影子练习作为独立训练类型在素材选择后出现，而非隐藏在无稿同传内部。

训练参数：

  • 跟述语言：源语跟述 / 译语跟述
  • 跟述类型：音位跟述（几乎同步） / 片语跟述（滞后 2—3 秒或用户设定）
  • 目标 EVS：用户设定目标滞后秒数，训练中计时器显示当前大致滞后，复盘时对比目标与实际

复盘：双轨回放同上，额外显示 EVS 偏差曲线（实际滞后与目标的偏离随时间变化），帮助建立稳定的听说时差感知。

3.3.4 同传训练录音策略

同传训练采用源语与译语双轨同步录制：源语音频轨与麦克风轨独立保存但共享同一时间基准。录制中若暂停源语播放，译语轨同步暂停，恢复时两轨同步继续，保证时间轴不漂移。该数据结构是复盘“原译对比”的基础。

3.4 复盘工作台

复盘是将“录音机”升级为“训练工具”的核心模块。所有训练模式结束后进入统一复盘工作台，根据训练类型展示不同默认视图。

3.4.1 双轨波形与同步回放

界面主体为上下两条对齐波形轨：上轨源语音频，下轨用户译语录音（交传按分段展示，同传整段展示）。两轨共享时间轴，播放头同步移动。

播放模式：

  • 源语单独播放
  • 译语单独播放
  • 源译混合播放
  • 双耳分听（使用耳机时）：左耳源语、右耳译语，或反之，可切换。

使用户在回听自己输出的同时即时对照源语信息，定位“哪里漏了、哪里偏了、哪里卡了”。

3.4.2 时间锚点标记与问题分类

用户可在波形任意位置点击添加时间锚点标记，并选择问题类型：

  • 忠实度类：漏译、误译、增译、数字/专有名词错误
  • 流利度类：长时间停顿、填充词（嗯/呃）、自我修正、重复
  • 表达类：语法错误、用词不当、语速失控
  • 策略类：EVS 过短/过长、笔记未利用（交传）

标记显示在波形轨上方，点击标记直接跳转。复盘时可按问题类型筛选，快速定位同类问题。

标记统计摘要：复盘页顶部显示本轮标记分布概览（如“漏译 3 处，长停顿 5 处，数字错误 1 处”），并与该用户同素材上一轮或近期平均水平对比。

3.4.3 自动评估线索（AI 辅助）

自动评估定位是提供可解释线索，而非替代自我判断。基于可解释 AI 的口译评估研究表明：神经翻译评估指标对忠实度有较强预测力，停顿相关特征对流利度有较强预测力。

一期可输出：

维度 自动线索 呈现方式
流利度 停顿次数、平均停顿时长、发声时间比、语速（WPM/CPM） 数值 + 波形上自动标注长停顿位置
忠实度（若源语 ASR 可用） 译语与源语 ASR 文本的语义相似度线索、数字/专有名词匹配情况 以“高风险片段”列表呈现，而非单一分数
覆盖率 源语关键实体在译语中的出现情况 实体列表 + 是否命中

关键约束：自动指标不给出“总分”，避免形成误导性权威感。界面措辞为“线索”“参考信号”，并明确说明这些指标无法替代自我判断。

3.4.4 笔记回放（若启用）

若交传中使用了数字笔记板，复盘时可开启“笔记回放”：笔记书写轨迹按时间戳逐笔重现，并与源语播放同步。使用户审视“笔记哪些部分在翻译时真正被用到、哪些是无效记录”。

3.4.5 复盘报告导出

用户可将本轮复盘导出为个人学习报告（PDF/图片/文本摘要），包含：素材信息、训练类型、波形截图、标记统计、自动线索摘要、个人备注。便于个人归档或作为学习记录留存。不设分享到公开社区功能。

3.5 个人成长追踪

3.5.1 训练历史

  • 按素材、训练类型、日期筛选训练记录。
  • 每条记录显示时长、问题标记数、自动线索摘要。
  • 支持对某条记录继续复盘、重练、删除。

3.5.2 趋势与对比

  • 同一素材多轮训练的流利度线索（平均停顿时长、语速）变化曲线。
  • 不同素材累计训练时长与标记问题类型分布。
  • 回炉对比：选择同一素材两次训练记录，并排进入复盘工作台，双轨波形和标记可叠加对比。

3.5.3 训练计划与目标（自学增强）

  • 用户可设定个人训练目标：如“每周交传 3 次、同传 2 次”“本月完成 20 段交传复盘”。
  • 系统在个人看板展示完成进度与连续训练天数。
  • 支持为某素材设置“计划重练日期”，到期提醒。
  • 不设教师布置任务；所有计划由用户自行创建和调整。

3.5.4 成就与激励（轻量）

  • 连续训练天数、累计训练时长、完成复盘次数等个人成就徽章。
  • 仅本人可见，不做社交排行，避免外部比较干扰自学节奏。

3.6 快捷键与训练效率

自学场景中操作摩擦直接影响训练连续性。建议提供：

快捷键 功能
Space 播放/暂停
R 重播当前分段/从头播放
M 添加时间锚点标记
1/2/3/4 快速选择问题类型
←/→ 前后跳转 5 秒
S 切换源语/译语/混合播放

4. 非功能需求

4.1 音频与实时性

  • 录音采样率不低于 16 kHz，单声道；源语音频播放推荐 44.1/48 kHz，录音轨可 16 kHz 控制存储。
  • 使用 Web Audio API + AudioWorklet 低延迟采集与实时波形/音量获取。
  • 播放与录音同步误差控制在 100 ms 以内；同传双轨录制 10 分钟连续训练时间漂移不超过 200 ms。
  • 波形前端渲染，长音频降采样分块加载，避免卡顿。

4.2 分段与 ASR 处理时延

  • 智能分段为非实时预处理。5 分钟音频分段计算目标 30 秒内完成，长音频允许异步处理并通知。
  • ASR 词级时间戳精度目标为“几个十分之一秒”级别，对句子边界重组足够；ASR 文本不保证 100% 准确，边界以“推荐”而非“强制”呈现，用户可手动修正。

4.3 兼容性与可访问性

  • 浏览器：Chrome / Edge / Firefox / Safari 最近两个大版本。
  • 桌面端优先保证录音与训练体验；移动端至少支持复盘回听与标记查看。
  • 键盘快捷键覆盖核心训练操作。

4.4 数据、隐私与合规

  • 单用户产品，所有素材、录音、复盘记录默认仅本人可见，无公开分享、无社交展示。
  • 提供“删除单条训练录音”“删除素材及关联记录”“删除账号及全部数据”入口，删除即时生效。
  • 支持数据导出（个人训练记录、复盘报告），便于用户迁移或归档。
  • 若面向欧盟用户需符合 GDPR 对语音数据的处理要求；面向国内场景遵循个人信息保护相关规定。注册和首次上传时以清晰语言告知数据用途。
  • 可选“纯本地模式”：素材与录音仅保存在浏览器本地存储/IndexedDB，不上传云端；用户需自行承担换设备丢失风险，产品需明确提示。

5. 页面与交互流程

5.1 交替传译训练路径

素材选择/上传
  → 分段参数设置（目标时长、浮动范围）
  → 系统分段 → 分段列表预览与微调
  → 逐段训练（播放→录音→下一段）
  → 训练完成 → 进入复盘工作台
  → 双轨回听 + 标记问题 + 查看自动线索
  → 保存复盘记录 / 重练本段 / 导出报告

5.2 带稿同传训练路径

素材选择（音频 + 文本稿件）
  → 文本-音频对齐（自动 + 手动校准）
  → 训练界面配置（字号、是否隐藏文本、术语高亮、遮挡设置）
  → 同传训练（源语播放 + 译语录制，文本同步高亮滚动）
  → 结束 → 复盘工作台（双轨 + 文本视图联动）

5.3 无稿同传训练路径

素材选择
  → 训练模式选择：标准无稿同传 / 影子练习
  → 参数配置（语速、EVS目标、干扰音开关）
  → 极简界面训练（源语播放 + 译语录制 + 可选EVS标记）
  → 结束 → 复盘工作台（双轨 + EVS标记/偏差）

6. 功能优先级清单（单用户自学版）

优先级 功能 所属模块 理由
P0 智能分段边界置信度显示与手动微调 交传 基础需求“时长浮动”的落地保障
P0 双轨波形同步回放 + 时间锚点问题标记 复盘 复盘最小可用能力，解决“找不到问题位置”痛点
P0 带稿同传文本-音频对齐与高亮滚动 同传 带稿同传区别于“放音频看稿”的核心价值
P1 影子练习独立入口 + EVS 目标与偏差复盘 同传 同传自学标准预备环节，低成本提升训练完整性
P1 个人术语库导入/提取/高亮/闪卡 准备与复盘 术语是口译训练高频刚需，串联素材准备与带稿同传
P1 训练历史、回炉对比、个人趋势 个人成长 自学平台的核心留存能力
P1 训练计划与目标、轻量成就 个人成长 替代外部教师监督，帮助自学者维持节奏
P2 自动流利度/忠实度线索（可解释，非总分） 复盘 在双轨与标记之上提供“看什么”的引导
P2 笔记回放 交传复盘 对交传价值高，实现成本较高
P2 文本遮挡训练 带稿同传 帮助从带稿向无稿过渡的脚手架
P2 复盘报告导出 复盘 个人归档与学习记录留存
P3 干扰音训练、纯本地模式 同传 / 系统 增值功能，视用户反馈排期

7. 技术方案要点

  • 录音与波形：Web Audio API + AudioWorklet 获取 PCM 与实时音量，前端绘制波形；录音编码 WAV/WebM 后存储。
  • ASR 与词级时间戳：Whisper 或同类模型启用词级时间戳；句子边界重组在应用层结合标点、停顿、句法信号完成，不依赖模型原生分段。
  • 句子边界检测：ASR 文本经句子切分器与词级时间戳对齐，生成候选边界及时间位置；长停顿通过 VAD 或波形能量分析获取。
  • 音频对齐（带稿同传）：ASR 文本与用户稿件模糊匹配，将稿件句子映射到音频时间区间；低置信度映射进入手动校准。
  • 自动线索：忠实度线索可基于 ASR 文本语义相似度指标（BLEURT/CometKiwi 类方法）；流利度线索基于录音轨停顿检测与计时统计；均在复盘阶段离线计算，不占训练实时资源。
  • 单用户数据模型：所有素材、录音、训练记录、术语库、标记均归属当前登录用户；无共享、无角色权限表。可选匿名本地模式不产生云端账号数据。
  • 存储：源语音频与用户录音分离存储；训练记录以结构化文档保存分段索引、时间锚点和标记数据。

8. 验收口径（关键项）

验收项 标准
交传智能分段 用户设定时长 ± 浮动范围内，输出边界经人工判断为“句子/意群结束处”的比例不低于 80%（基于测试集）
分段可编辑性 每段可独立试听、拖拽边界、合并/拆分，操作响应流畅
双轨复盘 源语与译语波形视觉严格对齐，播放头同步误差 ≤ 100 ms
带稿同传高亮 当前句高亮与音频进度一致，文本滚动跟随时间戳而非固定匀速
同传双轨录制 连续 10 分钟训练后源语轨与译语轨时间漂移 ≤ 200 ms
单用户数据隔离 任意用户无法访问他人素材、录音、复盘记录；产品无公开素材库与社交入口
数据可删除 用户删除训练记录/素材/账号后，相关音频与结构化数据在合理时间内不可恢复
无多角色入口 产品界面不出现教师端、班级、任务布置、批阅、互评等入口
