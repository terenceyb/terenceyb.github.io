一、认识存知

存知是一款「本地优先」的人脉工作台：把见过的人连成一张可检索、可回想的网，让每一次联系都有来处，也记得那些重要的日子。

它的三条基本主张：

  • 数据是你自己的文件：所有数据写在你选中的 .czdb 数据包里，可随时拷走、备份，不上传服务器、不用注册账号。
  • 本地优先：没有后端依赖，换设备或清缓存都不怕丢（前提是把数据包落到本地文件夹）。
  • 关系可回看：走动提醒、互动时间线、关系网络三套视图，帮你把「认识」变成「记得」。

核心概念

概念 说明
数据包（.czdb） 存知的全部数据容器，含人脉、待办、互动、纪念日、设置。可加密，可导出快照。
人脉 一个人脉记录，由若干字段（姓名、公司、电话……）＋关系备忘＋互动时间线组成。
互动 一次联系的记录（电话、见面、微信、礼物等），挂在某个人脉下，也可由速记快速生成。
走动提醒 按联系频率算出「久未联系」的人，提示你该打个招呼。
智能视图 用筛选条件保存下来的人群分组，可用于筛选人脉，也可参与走动提醒。

二、快速开始

首次打开会看到启动页，中间是诗句与三行可点的词胶囊，下方是三个入口。从上到下依次为：

2.1 三个入口

入口 作用 适合谁
先看看演示数据 载入 14 位示例人脉与完整关系网，进入体验态，可放心点遍所有功能。 第一次使用、想先逛一圈
从零开始 进入空白工作台，不预置任何业务数据。首次会弹出挂载引导。 确定要录入自己的数据
打开本地数据包 选择一个已有的 .czdb 文件加载；若文件加密，会转入口令解锁。 换设备继续用、恢复备份

2.2 给数据安一个固定的家

选择「从零开始」后首次会弹出挂载引导，标题为「把数据存到你的文件夹」，引导语「给数据安一个固定的家」。两个选项：

  • 选择本地文件夹：调用系统的保存窗口，默认文件名「我的存知数据包.czdb」。选定后每次改动都会自动写回这个文件，换设备、清缓存都不怕丢。
  • 暂不，用浏览器缓存：数据仅存在浏览器本地缓存，界面会明确提示有数据丢失风险。之后仍可在「设置 → 数据包管理」里补做挂载。

提示：不支持文件直接写入的浏览器会以「下载 / 导出覆盖」方式保存，功能不受影响，只是每次保存需手动确认下载。

2.3 结束体验，正式使用

在演示数据体验态下，每个页面的顶栏都会显示一个醒目的「结束体验，正式使用」按钮（位于「文件保存状态」左侧）。点击后二次确认：

  • 确认框标题「结束体验，正式使用？」，说明会清空全部示例人脉、待办、互动与纪念日；
  • 按钮「清空示例，正式开始」／「再体验一会」；
  • 点「清空示例，正式开始」后回到空白工作台，并弹出一次与「从零开始」相同的挂载引导。

「载入示例数据」支持撤销回退；「结束体验清空」不可撤销，请在确认前确认不再需要示例内容。

三、界面总览

3.1 桌面端

区域 内容
左侧栏 顶部为「存知」Logo（点「回首页」）与「折叠侧栏」按钮；导航项：首页、人脉、互动记录；「智能视图」分组（你保存的视图）；「系统」分组下的设置；底部为个人名片入口。
顶栏 左侧为保存状态胶囊（体验态时其左侧有「结束体验，正式使用」按钮）；右侧三个图标按钮：全局搜索、速记、新建人脉。
主区 当前页面内容；人脉详情页左侧边缘可拖动调整面板宽度。

折叠侧栏后只显示图标，鼠标悬停出提示；再点展开按钮恢复。

3.2 移动端

区域 内容
顶栏 显示当前页标题（首页为「存知」Logo），右侧为搜索 / 速记 / 新建等操作图标。
底部导航 四个标签：首页、人脉、互动记录、设置。
右下角圆钮 展开六格快捷操作：速记、新建人脉、新建待办、记录互动、导入数据、全局搜索。

3.3 快捷键（桌面端）

快捷键 功能
Ctrl / Cmd + K 打开全局搜索
Ctrl / Cmd + Shift + N 打开速记
Ctrl / Cmd + N 新建人脉
Ctrl / Cmd + Z 撤销（非输入状态时）
Esc 关闭联系人详情 / 弹窗
↑ ↓ Enter 在全局搜索里切换结果并打开

系统开启「减少动态效果」后，所有动画自动关闭，功能不受影响。

四、工作台（首页）

首页顶部按当前时段问候（夜深了 / 早上好 / 中午好 / 下午好 / 晚上好），并给一句数据概览；右上角「恢复默认布局」可把卡片位置与折叠状态复原。

首页有三张可拖动、可折叠的卡片，顺序可在「设置 → 外观 → 首页卡片顺序」调整（手机端）：

4.1 走动提醒

  • 列出该联系的人：头像、姓名、分组、上次互动时间、建议、逾期天数。
  • 操作：已联系（记一次联系并重置计时）、记录互动（填写详情）、多选（Shift 连选后批量记录互动）。
  • 没有待提醒的人时，显示「随机翻一张名片」。

4.2 待办事项

  • 按逾期 / 今天 / 本周分组，显示标题、关联人、截止日、逾期天数；重要待办带「●」标记。
  • 勾选完成时，若有关联人，可选「完成并记录互动」或「仅完成」。
  • 按钮：待办中心（进入完整列表）、新建待办。

4.3 纪念日

  • 展示未来 7 天内的生日 / 合作周年，标注「今天·当天」或「X 天后」，当天高亮。
  • 按钮：从生日字段导入（把人脉里填了生日的人一键创建为纪念日）。

小技巧：拖动卡片标题可调整位置，撞到的卡片自动让位；折叠状态与顺序保存在本机。

五、人脉管理

5.1 新建与编辑人脉

点击「新建人脉」（顶栏图标或人脉页按钮），弹窗标题「新建人脉」；编辑时标题为「编辑「姓名」」。

  • 头像：点击上传，支持 JPG / PNG / WebP，自动压缩成正方形。
  • 基础信息：姓名等核心字段。
  • 联系方式：电话、邮箱（工作 / 个人 / 其他）等多通道字段。
  • 自定义字段：可在「设置 → 字段管理」里增删，这里会同步出现。
  • 关系备忘：自由文本，可参与全局搜索，适合记「怎么认识的、有什么偏好」。

字段类型支持：文本、长文本、数字、复选框、单选、多选、日期（可含时间）、链接、联系方式、邮箱、地址、条码 / 名片码、附件、关联人脉。

必填项由「字段管理」决定，字段旁显示红色 *（提示「XX 为必填」）；联系方式类必填要求至少填一项，另校验邮箱格式、数字上下限与日期合法性。校验失败会提示「请检查标红字段」。

底部按钮：保存并继续添加、取消、保存。

5.2 人脉列表

进入「人脉」页，可用四种视图（手机端无表格视图）：

视图 说明
卡片 Wallet 名片堆叠效果，顶部为固定卡，点下方叠放卡可将其置顶。
宫格 一页多张名片卡，带 3D 倾斜动效。
表格 仅桌面端；可「配置列」（全选 / 全不选 / 恢复默认）、点表头排序、点单元格直接改字后「保存 / 撤销」。
关系网络 以图的方式查看人脉关联（详见第七章）。
  • 搜索：搜索框「在结果中搜索…」，匹配姓名、拼音全拼 / 首字母、公司。
  • 排序：最近互动 / 姓名拼音 / 添加时间 / 走动紧迫度。
  • 筛选：见第八章。

名片卡交互：点「查看背面信息」翻面；「更多」菜单含打开详情、拨打电话、复制电话、标记为已联系、删除联系人。表格视图支持 Shift 连选后批量打标签、改群组、设频率、导出、删除。

5.3 人脉详情

点任一名片进入详情页，主要内容：

区块 能做什么
头部 头像、姓名、群组、单位·职务·城市、上次互动、记录条数；可「记录互动」，更多菜单含编辑全部字段、与其他人脉合并、导出 vCard、显示空字段、删除联系人。
置顶备注 可置于页首，重要信息一眼可见。
字段信息 显示完整度百分比；「管理字段」可增删；逐字段点击即改，联系方式可拨打 / 复制 / 添加。
关系备忘 添加 / 编辑。
互动时间线 按全部 / 备注 / 联系 / 礼物 / 待办 / 纪念日过滤；可批量删除、单条置顶 / 删除。
联系频率 跟随视图 / 全局及各档天数。
关联待办 新建待办、完成、删除。
纪念日 添加（类型 / 名称 / 日期，可每年循环）、删除。
名片码 由姓名、公司、联系方式自动生成，扫码即可存入对方通讯录。

「与其他人脉合并」流程：选人 → 逐字段对比 → 确认合并。

六、互动、速记与待办

6.1 记录互动

记录入口分布在多处，按需选用：

  • 人脉详情页右上角「记录互动」；
  • 首页走动提醒里的「已联系」或「记录互动」；
  • 移动端快捷菜单「记录互动」；
  • 速记弹窗里选「电话沟通 / 见面 / 微信沟通 / 邮件 / 礼物」并保存。

「记录互动」弹窗标题为「记录与「X」的互动」：选互动方式（默认电话，可「自定义」新增）；礼物类型需填「礼物内容 / 价值（元）」；正文填「这次聊了什么 / 补充说明」；可设「发生日期」与勾选「重置走动提醒计时」。按钮「取消 / 保存记录」。

6.2 互动记录页

侧栏「互动记录」进入，是按天分组的全局时间线（今天 / 昨天 / 前天 / 具体日期，每天标注条数）：

  • 搜索：搜索内容、联系人或渠道。
  • 类别筛选：全部 / 联系 / 备注 / 礼物 / 待办 / 纪念日。
  • 范围筛选：近 7 天 / 近 30 天 / 近 90 天 / 全部。
  • 条数统计：页头显示近 7 天互动次数、覆盖人数、近 30 天次数（手机端压缩显示）。
  • 单条操作：点头像 / 姓名查看联系人；「置顶到该联系人详情页 / 取消置顶」；「删除这条记录」。
  • 空态可「查看全部互动」或「去人脉页」。

互动页不提供独立的新增按钮——记录在对应的人脉上产生，保证每条互动都有归属。

6.3 速记

一个轻量输入框，适合想到就记：文本提示「刚聊了什么？一句话就够…」，选渠道（普通备注 / 电话沟通 / 见面 / 微信沟通 / 邮件 / 礼物），「关联到」会按内容推荐联系人，也可「从全部联系人中选择」。

保存：Ctrl / Cmd + Enter；关闭：Esc。按钮「取消 / 保存到时间线」。

6.4 待办中心

从首页待办卡点标题进入，标签页为：全部 / 进行中 / 逾期 / 已完成 / 回收站（均带数量）。

  • 按钮「新建待办」：填标题、关联人脉、截止日期、优先级（普通 / 重要）。
  • 每行可勾选完成、查看关联人、显示截止 / 逾期天数。
  • 「删除到回收站」后，在回收站内可「恢复」或「彻底删除」。

七、关系网络

从人脉页的「关系网络」视图进入，顶部切换三种模式：

模式 说明
全览 节点图，颜色按群组、大小按关联人数；90 天内有互动为实心，黑点代表「我」。点节点弹出预览（关联人数、上次互动），含「查看详情 / 记录互动」。滚轮缩放、拖动平移，右下有放大 / 缩小 / 重置视图。节点数超 200 时只显示最近互动的 200 人；手机端超 80 节点自动降级为只读列表。
引荐树 按「引荐人」字段构建的有向树，顶部显示直接认识人数与网络总人数；节点可展开 / 折叠，显示「带来 X 人」。检测到「引荐环」会提示去详情页调整。
两人之间 基于「关联人」字段计算最短路径，选「从」「到」后显示「找到一条关联路径（X 跳）」与共同关联人（上限 4 跳）；无路径时给出「弱关联参考」（共同群组 / 标签）。

关系网络为只读视图，不会改动你的人脉数据。

八、搜索与智能视图

8.1 全局搜索

入口：顶栏搜索图标、移动端快捷菜单「全局搜索」或 Ctrl / Cmd + K。

  • 有关键词时按联系人聚合展示结果（姓名 + 群组 + 高亮片段）。
  • 无关键词时显示「搜索历史」（可清空）、「最近查看」、「最近添加」。
  • 搜索覆盖：姓名及拼音、公司、标签、备注、字段值与附件名。
  • ↑ ↓ 切换结果，Enter 打开，Esc 关闭。

8.2 筛选与智能视图

人脉页「筛选」面板支持：

  • 条件组合：字段 = 全部字段 + 虚拟字段（互动活跃度、添加时间、生日月份、字段完整度）；支持「且 / 或」、嵌套条件组、「非」取反。
  • 快速筛选：按群组过滤。
  • 命中漏斗：实时显示筛选命中过程。
  • 底部按钮：「全部清除 / 保存为智能视图 / 应用（N 人）」。

「保存为智能视图」后，该视图出现在侧栏的「智能视图」分组，可长期复用。在「设置 → 智能视图」里可设置某视图「用于走动提醒」（系统视图不可改），并查看与其他视图的重叠人数。

九、我的名片

侧栏底部或个人入口进入「我的名片」，页面提示「信息随数据包带走，不进服务器」。

  • 点头像旁的相机按钮上传头像。
  • 填写昵称（必填）、公司 / 单位、城市、电话、邮箱（校验格式）。
  • 「分享与导出」：导出 vCard（导入通讯录）、复制名片文字（粘贴到聊天做自我介绍）。

十、设置

移动端设置为两级菜单：一级为分组清单（图标 + 名称 + 一句说明 + 右箭头），点进二级页后顶部点「设置」返回。共 10 个分组：

分组 主要设置
我的信息 昵称、头像与简介（随数据包导出）
外观 主题、主题色、对比度、首页卡片顺序
字段管理 自定义字段的增删改、顺序与必填
数据包管理 当前文件状态、打开 / 另存 / 关闭 / 重新授权、加密、快照
导入导出 CSV / vCard 导入、数据包合并、多格式导出、名片册打印
提醒策略 默认联系频率、提醒时间、纪念日提前量、降权与系统通知
智能视图 视图的提醒用途、查看 / 编辑 / 删除
数据健康 缺失项与重复项体检、缓存清理
隐私与安全 应用锁 PIN、备份提醒、清除所有数据
关于存知 版本、开发者、官网、交互样张、数据与隐私说明

10.1 外观

  • 主题：跟随系统 / 浅色 / 深色。
  • 主题色：靛蓝（默认）、素白、松绿、远海、梅紫、珊瑚、竹青、青碧、玫红，另有「自定义」取色。
  • 提高全局对比度：文字更深、描边更实，强光下更清楚。
  • 首页卡片顺序（仅手机端）：待办事项 / 走动提醒 / 纪念日，可上移下移。

10.2 数据包管理

「当前数据包」显示文件名、修订号、最后保存、人脉数量、数据体积、格式版本与状态（已保存 / 有未保存更改 / 保存中 / 保存失败 / 未关联文件）。

  • 打开数据包 / 另存为 / 关闭数据包 / 重新授权。
  • 口令加密数据包：AES-GCM 加密，口令至少 6 位，默认关闭。忘记口令无法恢复。
  • 快照：加载超过 24 小时自动生成，最多保留 5 份；可「立即快照」与「恢复」。
  • 字段变更审计：保留最近 200 条。

保存异常时界面会出现横幅，提供「重试 / 重新授权」「另存为」「导出覆盖」；若检测到文件在外部被修改，会弹出冲突处理框：「另存为 / 重新加载文件 / 用本地版本覆盖」——存知不会静默覆盖你的任何一份数据。

10.3 导入导出

  • 导入：CSV / vCard，三步向导「上传预览 → 字段映射 → 冲突处理」，上限 2000 条；冲突可选跳过重复项 / 覆盖现有记录 / 作为新记录。支持「下载 CSV 模板」。
  • 合并导入数据包：.czdb / JSON，按记录级合并，冲突逐字段确认，不静默覆盖。
  • 导出：完整数据包 .czdb、CSV 表格、JSON 完整快照、vCard 名片。
  • 名片册打印：每页 6 张，首页为「我的名片」封面。

10.4 提醒策略

  • 默认联系频率：7 / 14 / 30 / 60 / 90 / 180 / 365 天（默认 30）。
  • 每日提醒时间：设定一个时间点。
  • 纪念日提前提醒：1 / 2 / 3 / 5 / 7 天。
  • 连续忽略降低权重：连续两次忽略同一人的提醒，第三次自动降权，避免提醒疲劳。
  • 浏览器系统通知：点「申请授权」；未授权时降级为应用内提示。

频率优先级：个人级 > 智能视图级 > 全局默认。

10.5 字段管理

增删自定义字段、调整顺序、设定必填与字段类型。首页卡片、人脉表单、筛选条件会同步使用这些字段。开启必填后，编辑表单里对应字段会显示红色 *。

10.6 数据健康

点「开始体检」，检查项包括：缺少电话 / 邮箱 / 头像、疑似重复、超过 90 天无互动、生日 30 天内但未设纪念日、引用了已删除联系人。可「清理缓存」，疑似重复联系人可「去合并」。

10.7 隐私与安全

  • 数据存储位置：本地。
  • 锁定应用（PIN）：设置 4 位 PIN / 取消 PIN / 立即锁定；忘记 PIN 可「继续使用（数据仍在本机）」。
  • 备份提醒：显示已备份 / 未备份与上次备份时间。
  • 清除所有数据：危险操作，需输入「删除所有数据」确认，不可恢复。

10.8 关于存知

显示版本信息（Beta V1.0 · 浏览器版）、开发者、联系方式与软件官网，并提供一个可拖动的「弹性面板缩放」交互样张，以及数据与隐私说明。

十一、数据安全与常见问题

数据安全

  • 所有数据只写在你选中的 .czdb 文件里，不上传服务器、不注册账号。
  • 建议把数据包放在本地文件夹并开启自动回写；重要数据可定期用「立即快照」或「导出完整数据包」备份。
  • 需要更高安全等级时开启「口令加密数据包」，但请务必记住口令——忘记后无法恢复。
  • 登录 / 支付类需求不在本应用范围；应用不收集、不上传你的通讯录内容。
